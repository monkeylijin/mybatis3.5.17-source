## 💡 学习建议

### ✅ DO - 推荐做法

1. **理论与实践结合**
   - 边看源码边调试
   - 每学完一个标签就动手实践
   - 对比生成的SQL理解原理

2. **循序渐进**
   - 先理解简单标签（`<if>`）
   - 再学习复杂标签（`<foreach>`）
   - 最后综合应用

3. **多问为什么**
   - 为什么要设计SqlNode树？
   - 为什么需要额外参数？
   - 性能差异的根本原因是什么？

### ❌ DON'T - 避免做法

1. **不要死记硬背标签语法**
   - 理解原理比记住语法更重要
   - 会查文档即可

2. **不要只看不练**
   - 动手实践才能真正理解
   - 调试源码加深印象

3. **不要忽略性能**
   - 了解动态SQL的性能开销
   - 学会权衡使用场景
