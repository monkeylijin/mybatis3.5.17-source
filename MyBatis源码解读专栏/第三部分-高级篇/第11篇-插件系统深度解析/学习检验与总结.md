# 第11篇：学习检验与总结（插件系统）

## 1. 知识点快速总结

### 1.1 插件系统的本质

- 插件系统不是字节码增强，也不是通用 AOP
- 它基于 **JDK 动态代理**，只代理 MyBatis 的四大接口对象
- 通过 `@Intercepts/@Signature` 精确声明可拦截的方法集合
- 通过 `Invocation.proceed()` 把代理链串起来

### 1.2 四大拦截点（必须记住）

- Executor
- StatementHandler
- ParameterHandler
- ResultSetHandler

它们覆盖了：调度与缓存、语句、参数、结果处理四个关键阶段。

### 1.3 插件生效时机

- XML 解析阶段：`XMLConfigBuilder` 只负责创建插件实例并注册到 `Configuration`
- 运行阶段：`Configuration.newExecutor/newStatementHandler/newParameterHandler/newResultSetHandler` 创建对象时统一 `pluginAll`

### 1.4 插件顺序

- `InterceptorChain` 按注册顺序 wrap
- 最后注册的插件成为最外层代理，通常最先进入 `intercept()`
